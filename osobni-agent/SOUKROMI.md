# Mozek: ochrana soukromí

Mozek je osobní nástroj jednoho člověka, majitele účtu Google, který ho připojil. Nikomu
dalšímu neslouží.

- **Co čte:** jen data majitele účtu z Google Health, a to jen pro čtení: spánek, aktivitu
  a zdravotní ukazatele (klidový tep, variabilitu tepu, okysličení krve, dech, teplotu kůže).
- **Kde je ukládá:** jen jako denní souhrny v počítači majitele, na šifrovaném disku.
- **Komu je dává:** nikomu. Žádné třetí strany, žádná reklama, žádný prodej dat a žádné
  posílání do cloudových služeb. Do Googlu nic nezapisuje.
- **Jak přístup zrušit:** na [myaccount.google.com/permissions](https://myaccount.google.com/permissions)
  vyber aplikaci Mozek a odeber jí přístup.

Data z Google API se používají v souladu se zásadami Google API Services User Data Policy,
včetně požadavků Limited Use.

## Privacy policy (English)

Mozek is a personal tool used only by the owner of the Google account that connected it.

- **What it reads:** only the account owner's Google Health data, read-only: sleep, activity
  and health metrics (resting heart rate, heart rate variability, oxygen saturation,
  breathing rate, skin temperature).
- **Where it stores it:** only as daily summaries on the owner's own computer, on an
  encrypted disk.
- **Who it shares it with:** nobody. No third parties, no advertising, no sale of data and no
  transfer to cloud services. It writes nothing to Google.
- **How to revoke access:** open [myaccount.google.com/permissions](https://myaccount.google.com/permissions),
  select Mozek and remove its access.

Mozek's use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
